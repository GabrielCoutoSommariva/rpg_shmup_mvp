# RPG + Shoot'em Up (Arcade) — MVP Starter (Patched)

## Requisitos
- Python 3.10+
- `pip install arcade`

## Rodar
```bash
python -m game.main
```
ou
```bash
python game/main.py
```

## Observação
Corrigido uso das funções do Arcade para retângulos: `draw_lrbt_rectangle_*` (left, right, bottom, top).
